# noxcipher.site

Personal lab for detection engineering on Microsoft Sentinel and Defender XDR.

- **Live:** https://noxcipher.site
- **Tools:** https://tools.noxcipher.site ([repo](https://github.com/xdemhdx/noxcipher-tools))

`brand/` holds the logo (`noxcipher-mark.svg`) and the brand guide (`noxcipher-brand.md`): colours, type and logo rules.
